Record a pattern

  1. Name the pattern uniquely
  2. Press ARM RECORDING
  3. Switch focus to the level/banner page
  4. Press F8 to start
  5. Jump
  6. Press F9 to stop and save
02 / REPLAY

Play a pattern

  1. Select the pattern
  2. Press ARM PLAYBACK
  3. Switch focus to the level/banner page
  4. Press F8 to start
  5. Watch and enjoy

How to use

F8 Start Record or PlaybackSpace JumpF9 Stop and SaveF10 Cancel

This dashboard controls a Python process on the same computer. The browser alone cannot send game input. Before pressing F8, switch to Geometry Dash and display the level-selection screen. F8 clicks the level title/banner automatically and uses the resulting scene change to synchronize recording or playback. The detected transition is not an exact simulation frame. Precise replay depends on matching level start, game speed, and frame timing. Geometry Dash is a trademark of its respective owner; this is an unofficial fan utility.
